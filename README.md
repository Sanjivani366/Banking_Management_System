# 🏦 BankEase – Banking Management System

A **Core Python-based Banking Management System** that simulates basic banking operations through a simple menu-driven application.

## 📌 Project Overview

BankEase allows users to create and manage bank accounts and perform basic banking transactions such as deposits, withdrawals, balance checking, money transfers, and transaction history management.

## ✨ Features

* Create a new bank account
* View account details
* Deposit money
* Withdraw money
* Check account balance
* Transfer money between accounts
* View transaction history
* Delete an account
* Duplicate account number validation
* Basic input and transaction validation

## 🛠️ Technologies Used

* **Python**
* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* User Input

## 🔄 Banking Operations

```text
Create Account
      ↓
View Account
      ↓
Deposit / Withdraw
      ↓
Check Balance
      ↓
Transfer Money
      ↓
Transaction History
      ↓
Delete Account
```

## ▶️ How to Run

1. Open the project in **Google Colab** or any Python environment.
2. Run the code.
3. Select an option from the main menu.
4. Enter the required account and transaction details.

## 📋 Main Menu

```text
1. Create Account
2. View Account
3. Deposit Money
4. Withdraw Money
5. Check Balance
6. Transfer Money
7. Transaction History
8. Delete Account
9. Exit
```

## 🎯 Project Objective

The objective of this project is to apply **Core Python programming concepts** to develop a practical banking application and understand how programming logic can be used to manage accounts and transactions.
